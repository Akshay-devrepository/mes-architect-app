# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to
**primeatnit@gmail.com** with `[SECURITY] MES Architect` in the subject —
not as a public GitHub issue, so a fix can ship before details are public.

Include what you found, how to reproduce it, and which version you tested
(Settings → version in the Android app, or `version.json` on the website).

## Supported versions

Only the latest release (website and Android APK) receives security fixes.
The Android app checks for updates on launch.
